# Pesse — Vanilla JavaScript demo

## 1.0.1 수정 및 GitHub 재배포

브라우저 기본 전역 속성 `top`과 충돌하던 함수 변수 이름을 `screenHeader`로 변경했습니다. 이 충돌은 첫 화면이 비어 있는 원인이었습니다.

압축을 해제한 **파일들**을 GitHub 저장소 최상위에 업로드하여 기존 파일을 교체하세요. ZIP 자체를 올리거나 하위 폴더로 감싸지 마세요. `index.html`, `app.js`, `style.css`가 같은 위치에 있어야 합니다. 변경을 커밋한 뒤 Actions의 Pages 배포가 완료되면 사이트에서 Ctrl+Shift+R로 새로고침하세요.

`package.json`은 개발 명령을 정의합니다. GitHub Pages는 HTML/CSS/JS를 직접 제공하므로 npm 실행이나 JSON 파일 자체가 배포 오류를 해결하는 것은 아닙니다.

로컬 개발: `npm run dev` 실행 후 `http://127.0.0.1:4173` 접속. 외부 패키지가 없어 `npm install`은 필요하지 않습니다. 검증: `npm test`.

## 실행

ZIP 파일을 압축 해제한 후 `index.html`을 브라우저로 열어 주세요. HTML, CSS, JavaScript만 사용하며 설치나 빌드가 필요하지 않습니다. 인터넷 연결이 없으면 웹 폰트 대신 기본 글꼴이 사용됩니다.

## 화면 순서

홈 → Send → 카드 선택 → 금액 입력 → Send money → 송금 중 → 송금 완료 → Done → 홈

- 송금 중 화면은 약 2.6초간 표시됩니다.
- Cancel 또는 송금 중 화면의 뒤로 가기 버튼은 송금을 취소합니다. 금액 입력 화면으로 돌아가며 잔액은 차감되지 않습니다.
- 완료 시 선택한 카드의 잔액과 홈 잔액이 차감되고 거래 내역이 추가됩니다.
- 완료 화면에는 수신자, 계좌번호, 선택한 카드 끝 4자리, 금액, 수수료, 실제 완료 시각이 표시됩니다.
- Done과 완료 화면의 뒤로 가기 버튼은 홈으로 이동합니다.
- 숫자 키패드 또는 키보드 숫자/Backspace로 금액을 입력할 수 있습니다.
- 수신자 변경, 카드 변경, 데모 카드 추가, 입금 정보, 거래 내역 화면도 포함되어 있습니다.

실제 금융 서비스에 연결되지 않은 데모입니다. 데이터는 메모리에 저장되며 새로고침하면 초기화됩니다.

## 파일

- `index.html`: 시작 페이지
- `style.css`: 전체 화면 스타일 및 애니메이션
- `app.js`: 화면 전환 및 데모 송금 처리
- `verify.cjs`: Node.js 기반 동작 검증 (`node verify.cjs`)

## 검증

`node --check app.js` 및 `node verify.cjs`로 문법과 송금 중/취소/완료, 중복 실행 방지, 잔액 검증, 선택한 카드와 수신자 반영을 확인할 수 있습니다.
