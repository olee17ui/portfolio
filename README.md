# 개인 포트폴리오 · 사용 안내

HTML / CSS / Vanilla JavaScript / JSON으로 제작했습니다. 설치하거나 빌드할 패키지가 없습니다.

## 페이지

- 메인: 큰 PORTFOLIO 타이포그래피와 중앙 대표 작업 한 장. 마우스 또는 키보드 포커스를 올리면 사진이 컬러로 전환되고 살짝 확대됩니다.
- WORK: 등록한 작업이 모두 표시되고, 작업 수에 따라 페이지가 아래로 길어집니다.
- 상세: 설명과 큰 이미지. 이미지를 누르면 확대되고 ESC로 닫힙니다.
- ABOUT: 가운데 사진과 아래 자기소개.
- editor.html: 개인 소개, 작업 추가·수정·삭제·순서 변경, 사진 선택, JSON 다운로드.

## 1. GitHub에 처음 올리기

1. ZIP을 압축 해제합니다.
2. GitHub에서 새 **Public 저장소**를 만듭니다. 예: `portfolio`.
3. 저장소의 **Add file → Upload files**에서 `portfolio` 폴더 **안의 내용**을 올립니다. `index.html`이 저장소 최상단에 있어야 합니다. ZIP 자체를 올리지 마세요.
4. `assets`와 `data` 폴더 구조도 그대로 포함하고 **Commit changes**를 누릅니다.
5. **Settings → Pages → Build and deployment**로 이동합니다.
6. Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 **Save**를 누릅니다.
7. 배포가 완료되면 Pages 화면의 주소를 엽니다. 일반적인 주소: `https://사용자이름.github.io/portfolio/`.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 2. 글과 이미지를 계속 추가하기

1. 사이트 주소 뒤에 `editor.html`을 붙여 엽니다. 예: `https://사용자이름.github.io/portfolio/editor.html`.
2. 이름, 이메일, 소개를 수정하거나 **+ 새 작업**을 누릅니다.
3. 제목, 분야, 연도, 설명을 입력하고 **표지 사진 업로드**로 사진을 선택합니다.
4. **상세 사진 추가**에서 여러 이미지를 선택할 수 있습니다. 경로 목록의 줄 순서를 바꾸면 상세 이미지 순서도 바뀝니다. 줄을 지우면 해당 이미지를 상세에서 제외합니다.
5. **작업 적용**을 누릅니다. 메인 대표 후보를 체크한 작업 중 첫 작업이 메인에 나옵니다. 체크한 작업이 없으면 목록의 첫 작업이 표시됩니다. WORK에는 전부 나옵니다.
6. **portfolio.json 다운로드**, 새 사진이 있으면 **새 이미지 다운로드**도 누릅니다. 브라우저가 여러 다운로드를 물으면 허용하세요. 파일 이름을 그대로 유지하세요.
7. GitHub에서 `data` 폴더를 연 뒤 **Add file → Upload files**로 새 `portfolio.json`을 올려 기존 파일을 교체합니다. 다운로드 이름이 `portfolio (1).json`이면 먼저 `portfolio.json`으로 바꿉니다.
8. GitHub의 `assets/images` 폴더에 내려받은 새 사진을 올립니다. 새 사진만 추가하면 됩니다. 기존 사진은 유지하세요.
9. 변경 사항을 Commit하고 배포 완료 후 새로고침합니다. 즉시 보이지 않으면 `Ctrl + F5`를 누릅니다.

편집 화면은 브라우저 안에서 파일을 준비하는 도구입니다. **작업 적용만으로 GitHub나 사이트가 바뀌지 않습니다.** 탭을 닫기 전에 JSON과 사진을 내려받으세요. 공개 편집 화면에 방문자가 접근해도 저장소를 수정할 수는 없습니다. 실제 반영에는 GitHub 저장소의 수정 권한이 필요합니다. 다운로드한 JSON을 **기존 JSON 가져오기**로 다시 불러와 이어서 편집할 수 있습니다. 새 사진은 별도로 보관해야 합니다.

## 3. JSON을 직접 수정하기

`data/portfolio.json`의 `profile`은 개인 정보, `projects`는 작업 배열입니다. 작업 하나의 예:

```json
{
  "id": "my-project-01",
  "title": "MY PROJECT",
  "category": "Photography / Design",
  "year": "2026",
  "summary": "작업 목록에 들어갈 짧은 설명",
  "description": "상세 설명입니다.\n줄바꿈도 가능합니다.",
  "cover": "assets/images/my-project.jpg",
  "images": ["assets/images/my-project.jpg", "assets/images/my-project-detail.jpg"],
  "featured": true,
  "isNew": true
}
```

`id`는 작업마다 다르게 지정하세요. 경로는 대소문자까지 실제 파일명과 같아야 합니다. 맨 앞에 `/`를 붙이지 마세요. 파일 이름은 영문 소문자, 숫자, 하이픈을 권장합니다. 배열의 순서가 표시 순서입니다. 항목 사이에 쉼표가 필요하고 마지막 항목 뒤에는 쉼표를 넣지 않습니다. 사진은 JPG 또는 WebP, 가로 1600~2400px 정도로 준비하면 상세에서도 선명합니다.

## 4. PC에서 미리 보기

JSON을 읽기 때문에 `index.html` 더블클릭 대신 로컬 서버를 사용해야 합니다.

- VS Code를 사용하는 경우: 폴더 열기 → Live Server 확장 설치 → `index.html`에서 Open with Live Server.
- Python이 있는 경우: `portfolio` 폴더 터미널에서 `python -m http.server 8000` 실행 → 브라우저에서 `http://localhost:8000` 열기.

## 파일 구성

```
index.html            공개 포트폴리오
style.css             반응형 디자인
app.js                메인·WORK·상세·ABOUT 표시
editor.html           콘텐츠 편집 화면
editor.js             편집 및 다운로드
data/portfolio.json   글과 이미지 경로
assets/images/        작품과 소개 사진
.nojekyll             정적 파일 배포 설정
```

이름, 연락처, 소개, 작품 제목과 설명은 교체용 샘플입니다. 첨부한 시안의 작품 및 인물 영역을 추출해 초기 이미지로 사용했으며, 일부는 작은 썸네일에서 가져와 확대 시 흐릿합니다. About 사진도 본인 사진으로 교체하세요. 모든 시안 이미지와 샘플 문구는 실제 작업 자료로 교체할 수 있습니다.


## ABOUT·INDEX 추가 기능

- ABOUT은 기본 정보, 자기소개, 경력, 학력·교육, 사용 도구, 선택 사항인 수상·자격으로 구성됩니다. editor.html의 개인 소개에서 입력하세요. 줄바꿈이 그대로 반영됩니다. 실제 이력 미입력 항목은 등록 예정으로 표시됩니다.
- INDEX는 `#/index`에서 열립니다. UI/UX, 로고, 상세페이지, 배너, AI 이미지의 설명과 작품 수를 보여줍니다.
- 작업 편집의 **목차 분류**를 선택하면 해당 INDEX 항목과 분야별 WORK 목록에 자동 반영됩니다. 기존 샘플은 미분류 상태이며 전체 WORK에서 볼 수 있습니다.
- JSON 작업의 `group` 값: `uiux`, `logo`, `detail`, `banner`, `ai`. 미분류는 빈 문자열 또는 생략입니다.
- INDEX 대표 사진은 개인 소개의 **INDEX 대표 이미지 경로**에서 변경합니다. 사진을 `assets/images`에 올린 후 해당 경로를 입력하세요.
- 추가 프로필 필드: `experience`, `education`, `skills`, `awards`, `indexImage`. 이전 JSON도 편집 화면에서 가져올 수 있습니다.

## 로고·브랜딩 페이지

- 로고: 작업 편집에서 **로고 (PNG)** 분류를 선택하고 투명 배경 PNG를 표지로 올리세요. 목록에서는 로고 전체를 잘리지 않게 표시하고, 클릭하면 큰 로고와 설명·역할·사용 도구가 있는 상세 페이지가 열립니다. 큰 이미지를 다시 누르면 확대되며 ESC로 닫힙니다.
- 브랜딩: **브랜딩** 분류를 선택하세요. 상단의 3열 이미지 목록에서 각 작업의 별도 상세 페이지로 이동합니다. 표지는 대표 목업, 상세 사진은 추가 적용 이미지로 사용합니다.
- 담당 역할과 사용 도구는 작업 편집의 해당 입력란에 작성합니다. JSON에서는 `role`, `tools` 문자열로 저장됩니다. 브랜딩의 `group`은 `branding`입니다.
- 첨부 시안으로 만든 브랜딩 3개는 레이아웃 확인용 샘플입니다. 실제 작업으로 교체하세요. 로고 PNG 원본은 아직 등록되지 않았으며 실제 파일을 올리면 로고 목록에 표시됩니다.

## 배너 목록 배치

배너 분류는 PC 4열, 태블릿 2열, 모바일 1열입니다. 각 칸은 위쪽 제목·짧은 소개, 아래쪽 이미지 순서로 표시합니다. 편집 화면에서 목차 분류를 배너로 설정하고, **짧은 소개**에 목록 설명을 입력하세요. 표지 이미지에는 배너 파일을 선택합니다. 가로·세로 이미지 모두 원본 비율을 유지합니다. 클릭하면 상세 설명과 큰 이미지가 열립니다. 첨부 레퍼런스에서 추출한 4개 샘플은 실제 배너로 교체하세요.

## AI 이미지 바인더 앨범

AI IMAGE는 두 장씩 펼쳐지는 바인더 앨범입니다. 좌우 버튼, 키보드 좌우 방향키, 좌우 스와이프로 넘길 수 있습니다. 이미지 클릭 시 해당 작업 상세 페이지로 이동합니다. OS의 동작 줄이기 설정에서는 회전 효과 없이 전환합니다.

편집 화면에서 작업 분류를 **AI 이미지**로 지정하고 상세 사진을 추가하세요. 작업 목록 순서, 각 작업의 상세 이미지 순서로 앨범에 들어갑니다. 상세 이미지가 없으면 표지를 사용합니다. 이미지 수가 홀수면 마지막 오른쪽 페이지는 종료 페이지로 표시합니다. 등록한 AI 작업이 없을 때는 기존 미분류 이미지로 구성한 배치 샘플을 표시합니다.

### 최신 표시 설정
본문 설명은 Noto Sans KR 웹폰트로 표시하며 이전 버전보다 1pt 확대했습니다. 웹폰트는 Google Fonts에서 불러오며 네트워크 연결이 없으면 기본 sans-serif로 표시됩니다. 바인더는 각진 테두리와 이미지가 가득 차는 배치로 변경했습니다(이미지 비율에 따라 가장자리가 잘릴 수 있습니다). 양옆 화살표에 마우스를 올릴 때 한 번씩 넘기며, 다시 넘기려면 커서를 밖으로 옮겼다가 올리세요. 터치에서는 화살표를 누르거나 스와이프하고, 키보드에서는 방향키를 사용합니다. 아래쪽 버튼·설명과 이미지 캡션은 화면에서 숨겼습니다.
